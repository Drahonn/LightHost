Light Host 2.1.0
---

A lightweight VST3/AU audio plugin host for macOS, Windows, and Linux that sits in the menu/task bar.
Built with JUCE 9.0.4.

### Features
- Native support for VST3 and AU plugins (JUCE 9.0.4)
- Automated background plugin scanning on launch
- Custom plugin directory management directly from the tray menu
- Real-time zero-glitch plugin bypass without graph reconstruction
- Mono-to-stereo routing with automatic warnings
- Audio input and output device selection
- Persistent plugin states and ordering
- Cross-platform: Windows (standalone .exe), macOS (native .dmg), Linux
- Modern C++20 architecture with high reliability

### Releases
Download prebuilt executables and installers from the [Releases](https://github.com/Drahonn/LightHost/releases) page:
- **Windows:** `LightHost.exe` (standalone executable)
- **macOS:** `LightHost.dmg` (native installer disk image)
- **Linux:** `LightHost-Linux` (standalone executable)
