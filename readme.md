Light Host
---

A simple VST/AU host for OS X, Windows, and Linux that sits in the menu/task bar.

### Features

Features
Add/remove plugins (AU/VST/VST3)
Change output and input
Plugin states saved
Saved plugin order
Cross platform
ASIO support
Plugin bypass
Plugin re-ordering
